--------------------------------

注意
--------------------------------
1. addSlot 的 x,y 是 16×16 物品区左上角，不是 18×18 槽框（框 = x−1, y−1）。
2. 产物格 24×24 比标准格大，物品要放 124,35 才居中。
3. 顶部 (65,34)、(47,52) 各有一段 1px 描边残留（画图拖出来的），做 mod 前建议擦掉。
4. 若做 2× 高清贴图（512×512），所有数值 ×2，blit 绘制尺寸也 ×2。
